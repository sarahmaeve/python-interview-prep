# Evidence Request Menu

Use this menu only after writing your own clarification questions and initial
hypotheses. The categories are a self-study substitute for asking a live game
master.

Open a packet when it matches an investigation you chose:

| If you would ask for or investigate... | Open |
|---|---|
| User impact, frequency, and the scope of affected operations | [Packet 1](evidence/01.md) |
| A precise timeline for one affected logical submission | [Packet 2](evidence/02.md) |
| Correlation between client operations and gateway requests | [Packet 3](evidence/03.md) |
| The gateway's contract for repeated requests | [Packet 4](evidence/04.md) |
| Relevant deployment, environment, or change history | [Packet 5](evidence/05.md) |
| A safe local reproduction of the reported behavior | [Packet 6](evidence/06.md) |

If your question is not represented, record it anyway. In a facilitated
session, the game master should answer from the scenario truth table or say
that the information is unavailable.
