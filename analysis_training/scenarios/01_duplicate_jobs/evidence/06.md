# Evidence Packet 6

A deterministic local reproduction models a gateway that accepts the first
request but loses its response. It records every key it receives and every
remote job it creates.

Run it from the exercise directory:

```bash
cd exercises/40_retry_idempotency
python3 reproduce_incident.py
```

The reproduction should eventually show one successful local result. The
diagnostic question is how many remote jobs were created for that one logical
submission, and which keys named the attempts.
