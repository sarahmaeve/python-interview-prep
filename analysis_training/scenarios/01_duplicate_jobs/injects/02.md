# Follow-Up Inject 2: Reused Operation Identity

A support tool accidentally reused `operation-8` for `delete-report` after the
same operation ID had completed `build-report`.

The submitter returned the earlier job result. It did not contact the gateway
and did not report that the new payload conflicted with the recorded logical
operation.

The required contract is:

- The same operation ID and same payload replay the existing operation.
- The same operation ID and a different payload are rejected as a conflict.

Determine why the component loses the evidence needed to enforce that
contract, then make the smallest repair.

Focused verification:

```bash
cd exercises/40_retry_idempotency
python3 -m unittest \
  test_job_submitter.TestOperationConflicts.test_same_operation_id_rejects_different_payload \
  -v
```
