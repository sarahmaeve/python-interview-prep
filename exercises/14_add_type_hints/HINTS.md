# Hints: Exercise 14 — Add Type Hints

## Hint 1

Use each docstring and the value's later operations to infer its type.

## Hint 2

You will need parameter and return annotations, container element types, and an
explicit optional type where `None` is accepted.

## Hint 3

Built-in `list[...]` and `dict[...]` forms are valid here. `Optional[X]` and
`X | None` are equivalent for this exercise; `self` need not be annotated.

The complete annotation table is in
[solutions/14_solution.md](../../solutions/14_solution.md).
