# Hints: Exercise 18 — Write Tests from Scratch

## Hint 1

Start with one normal example per public behavior, then add documented error and
boundary cases.

## Hint 2

Use `assertRaises` for invalid input and choose assertions that compare the
entire meaningful result, not merely its truthiness.

## Hint 3

The test skeleton's names and docstrings form a checklist. A complete reference
suite is discussed in
[solutions/18_solution.md](../../solutions/18_solution.md).
